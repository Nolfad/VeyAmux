# VeyAmux com NVIDIA DLSS e VFG

Este fork do [VeyAmux](https://github.com/8BiTw0LF/VeyAmux) adiciona suporte a DLSS Super Resolution e à geração de quadros via NVIDIA VFG no Linux.

Todos os testes foram feitos em placas da série GeForce RTX 30. Em teoria, esses recursos também podem funcionar em outras séries RTX, mas isso ainda não foi verificado.
